How to run a session

  1. Open this link and allow microphone access.
  2. Wait for local models and “Connected” beside the room.
  3. Choose a case and read its instruction; most scripts need a short spoken setup message before Run.
  4. Follow the case: speak and use the room controls, then click Run when instructed.
  5. Read its check and event log. If the connection breaks, click Reconnect agent or Restart room, then run the case again.
